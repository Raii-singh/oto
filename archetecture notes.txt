# 🚀 Build OTOwire-Lite – Cloud + DevOps Project

## 🧠 Context

You are building **OTOwire-Lite**, a cloud-native OTT aggregation platform.

This is a **Stage 2 inspired MVP** of OTO, where:

* Users can search content across OTT platforms
* View metadata (ratings, description, availability)
* Click and **redirect to the original OTT platform**
* For YouTube content → redirect directly to the video

⚠️ IMPORTANT:

* NO actual video embedding from Netflix/Prime (legal constraint)
* ONLY redirection-based playback

This aligns with the Stage 2 concept of unified experience without violating platform policies.

---

## 🎯 Goal

Build a **production-ready cloud-native system** that demonstrates:

* DevOps practices (CI/CD, containers, automation)
* Cloud architecture (scalable deployment)
* Microservices communication
* Observability & monitoring

---

## 🚧 STRICT SCOPE

### ✅ Build ONLY:

* Authentication system (JWT)
* Content aggregation (mock APIs or scraped dataset)
* Search system

## 🔌 API Design

### Auth:

POST /auth/signup
POST /auth/login

### Content:

GET /content
GET /content/:id

### Search:

GET /search?q=movie_name

### Watchlist:

POST /watchlist
GET /watchlist

### Redirect:

GET /redirect/:content_id

Logic:

* If platform = Netflix → redirect to Netflix URL
* If platform = YouTube → redirect to video link
